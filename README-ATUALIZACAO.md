# NULLWEAR — atualização do site

## Como atualizar no GitHub

1. Substitua o arquivo `index.html` pelo deste pacote.
2. Substitua `css/style.css` pelo arquivo atualizado.
3. Crie a pasta `js` e coloque nela o arquivo `script.js`.
4. Mantenha a pasta `img` que já existe no repositório.
5. Faça o commit das alterações no GitHub.

## O que funciona

- Menu para telas pequenas.
- Busca e filtros de produtos.
- Botões para adicionar produtos à sacola e contador de itens.
- Validação dos campos do formulário.
- Avisos na tela quando uma ação é realizada.

A sacola e os dados do formulário ficam salvos no navegador usado. O formulário não envia mensagens e a sacola não realiza compras reais. Os dados não são sincronizados com outros aparelhos.
